# AIオブジェクトマスク (ObjectMask) for AviUtl ExEdit2

動画の中の「切り抜きたい物体」を、ウィンドウ上でなぞって囲むだけで AI (SAM 2) が検出し、**それ以外の部分を透明にする**フィルタ効果プラグインです。
グリーンバックがなくても、人物・小物・動物などを切り抜けます。

- 種類: 汎用プラグイン (`.aux2`)
- フィルタ効果名: **AIオブジェクトマスク(ObjectMask)** (カテゴリ: クリッピング)
- バージョン: 0.03

---

## 主な機能

- **なぞるだけで切り抜き**: 独自ウィンドウに表示された映像上で、物体の周りをドラッグして囲むだけ
- **追加と除外**: 範囲は最大16個まで。「ここは残す」「ここは消す」を重ねて調整できる
- **自動追跡**: 動く物体にもマスクが追従する (オン/オフ切り替え可)
- **輪郭の仕上げ調整**: ぼかし・拡大縮小・縁の精密化・ゴミ除去・縁の色補正など
- **GPU対応**: DirectML による GPU 実行。使えない環境では自動的に CPU に切り替え
- **解析結果のキャッシュ**: 一度解析したフレームは再利用するので、再生・書き出しが速くなる

---

## 動作環境

- AviUtl ExEdit2
- Windows 10 / 11 (64bit)
- GPU (DirectML 対応) があると高速です。なくても CPU で動作します

## インストール

下記の構成で `Plugin` フォルダに配置してください。

```
Plugin\
 └ ObjectMask\
    ├ ObjectMask.aux2
    ├ onnxruntime.dll              (ほか ONNX Runtime 関連のDLL)
    ├ DirectML.dll                 (GPUで実行する場合)
    ├ licenses\                    (同梱物のライセンス文書)
    └ models\
       ├ sam2_encoder.onnx
       └ sam2_decoder.onnx
```

- `onnxruntime.dll` は、他のプラグインや Windows が読み込む別バージョンと混ざらないよう、**このプラグインのフォルダにあるものが優先して**使われます。
- `DirectML.dll` が見つからない場合は Windows 標準のものが使われ、環境によっては GPU で動かないことがあります。
- AviUtl ExEdit2 を起動すると、フィルタ効果「AIオブジェクトマスク(ObjectMask)」と、独自ウィンドウ「AIオブジェクトマスク」が追加されます。

---

## 使い方

1. 切り抜きたい映像のオブジェクトに、フィルタ効果 **AIオブジェクトマスク(ObjectMask)** を追加します。
2. そのオブジェクトを選択した状態で、独自ウィンドウ **AIオブジェクトマスク** を開きます。タイムラインのフレームが表示されます。
3. ウィンドウ上で、残したい物体を囲むようにドラッグします。
4. 離すと解析が始まり、検出された物体以外が暗く表示されます。問題なければそのまま完了です。
5. 検出が足りない/余計な部分が入った場合は、範囲を追加したり除外したりして調整します。

> 初回の解析時にモデルを読み込むため、少し時間がかかります。

### 独自ウィンドウの操作

| 操作 | 内容 |
|---|---|
| 左ドラッグ | フリーハンドで物体を囲む (追加) |
| Shift + 左ドラッグ | 四角形で囲む |
| 右ドラッグ | 囲んだ部分を対象から**除外** (範囲の中の、物体ではない部分を消したいとき) |
| `モード: 追加` / `モード: 除外` ボタン | 左ドラッグの動作を「追加」と「除外」で切り替え。除外モードでは左ドラッグも除外になる |
| `範囲をクリア` | 指定した範囲をすべて消す |
| `直前を取り消し` | 直前に指定した範囲を1つ取り消す |
| `解析キャッシュを破棄` | 保存済みの解析結果を破棄して、解析をやり直す |

- 範囲は **最大16個** までです。
- 除外は、追加した範囲がある状態で行ってください。
- 動く映像では、**基準フレーム** (範囲を指定したフレーム) と違うフレームで指定すると、位置がずれる場合があります。範囲は、物体がはっきり見えるフレームで指定するのがおすすめです。
- 再生中・書き出し中は、ウィンドウの表示更新を減らして負荷を抑えます。

## 設定項目

### 対象の枠

| 項目 | 内容 |
|---|---|
| 枠X / 枠Y / 枠幅 / 枠高さ | 対象の外接枠。ウィンドウでの操作に合わせて自動で設定されます |
| 基準フレーム | 範囲を指定したフレーム。追跡の起点になります |
| 選択範囲(自動設定) | ウィンドウで指定した範囲を保存する欄です。**手で編集しないでください** |

### 動作

| 項目 | 既定値 | 内容 |
|---|---|---|
| 追跡 | オン | 動く物体にマスクを追従させる |
| 解析間隔(フレーム) | 4 (1〜30) | 何フレームごとにAI解析を行うか。間のフレームは追跡で補います。小さいほど精度が上がり、重くなります |
| 反転 | オフ | 物体を消して、**背景を残す** |

### 輪郭

| 項目 | 既定値 | 内容 |
|---|---|---|
| ぼかし | 1.0 | 輪郭をぼかす |
| 拡大縮小 | 0.0 | マスクを広げる (+) / 縮める (−) |
| 時間平滑化 | 0.3 | 前後のフレームとなじませて、輪郭のちらつきを抑える |
| しきい値 | 0.5 | 物体と判定する境目。上げると厳しく、下げると広めに判定 |
| 輪郭補正 | 6.0 | 輪郭を画像の境目に沿うように整える |
| 縁の精密化 | 2.0 | 髪の毛など細かい縁を自然にする |
| ゴミ除去 | 6.0 | 小さな誤検出の点を消す |
| 形のなめらか化 | 1.0 | マスクの形のギザギザをなめらかにする |
| 透明度の下限 / 上限 | 0.10 / 0.90 | これ以下を完全な透明、これ以上を完全な不透明として扱う |
| 色の均一化 | 0.0 | 縁の色のむらを均す |
| 縁の色補正 | 2.0 | 縁に残った背景色の映り込みを抑える |

`解析キャッシュを破棄` ボタン: 保存済みの解析結果を破棄します。

---

## うまく切り抜くコツ

- 物体全体を、少し余裕をもって囲むと安定します。
- 余計な部分が入ったら、その部分を**右ドラッグで除外**します。
- 縁に背景色が残るときは「縁の色補正」「縁の精密化」を上げ、輪郭が太いときは「拡大縮小」をマイナスにします。
- 輪郭がちらつくときは「時間平滑化」を上げます。動きが速くて追従できないときは「解析間隔」を小さくします。

---

## キャッシュについて

- 解析結果は `Plugin\ObjectMask\ObjectMaskCache` フォルダに保存されます。
- 2週間以上使われていないもの、合計 1GB を超えた分は古いものから自動で削除されます。
- 動画やパラメータを変えても結果がおかしい場合は、`解析キャッシュを破棄` を押してください。

## トラブルシューティング

| 症状 | 対処 |
|---|---|
| 「モデルが見つかりません」 | `models` フォルダに `sam2_encoder.onnx` と `sam2_decoder.onnx` があるか確認してください |
| 「onnxruntime.dll を読み込めません」 | プラグインのフォルダに `onnxruntime.dll` を置いてください |
| 「…ビルドに使ったONNX Runtimeより古いため使えません」 | 同梱のバージョンの `onnxruntime.dll` を置いてください。他のプラグインのDLLと混ざっていないか確認してください |
| GPUで動かず、遅い | `DirectML.dll` がプラグインのフォルダにあるか確認してください。GPU実行に失敗した場合は自動でCPUに切り替わります |
| 「物体を検出できませんでした」 | 枠を描き直してください。物体がはっきり見えるフレームで指定すると改善します |
| 位置がずれる | 基準フレーム以外で指定していないか確認してください。「解析間隔」を小さくするのも有効です |
